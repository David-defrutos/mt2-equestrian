# Origen del contenido

Este mod es un **traspaso a Monster Train 2** del clan Equestrian de Monster Train 1:

- Obra original: **Equestrian Clan**, de **ThreeFishies**
  https://github.com/ThreeFishies/Equestrian-Clan (version 0.9.7.0, commit b4d11a4)
- El repositorio original declara que existe "for educational purposes" y no incluye
  fichero de licencia.

De ahi vienen el diseno del clan (cartas, campeones, reliquias, valores) y **todo el arte**.
Lo unico propio de este repositorio es la reimplementacion de esos datos en el formato
JSON de Trainworks Reloaded para MT2.

El universo de My Little Pony es propiedad de Hasbro. Ni el mod original ni este estan
creados ni respaldados por Hasbro, Shiny Shoe o Good Shepherd Entertainment.

**Uso personal.** Publicarlo en Thunderstore requeriria antes hablar con ThreeFishies.
